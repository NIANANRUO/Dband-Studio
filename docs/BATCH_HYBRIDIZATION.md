# 批量轨道杂化分析

入口：杂化分析窗口 → **批量分析…**。原有单次分析保持可用。

## 操作步骤

1. 在 Fragment 1、Fragment 2 中选择所需轨道，并在 Settings 中设置自旋。
2. 打开批量分析，勾选一个或多个已导入体系。
3. 为每个体系填写独立的原子编号。支持 `67,68,69,70`、`67，68，69，70`、`67-70` 和空格分隔；有结构信息时也可输入元素符号。
4. 选择配对方式，再点击 **预览任务**。预览会检查轨道能力、原子范围和可选的预期元素；任一已选体系不合法时，不允许运行残缺的任务计划。
5. 检查实际原子对和轨道列表，点击 **运行待处理任务**。
6. 点击已完成任务，主窗口显示对应三联图。取消保留已有结果，可以继续运行待处理任务，也可以单独重试失败任务。

## 六种配对方式

| 方式 | 左侧 / 右侧示例 | 输出 |
|---|---|---|
| 一对一 | 1 / 2 | 1–2 |
| 一对多：逐对 | 1 / 2,3 | 1–2、1–3 |
| 一对多：合并 | 1 / 2,3 | 1–{2,3} |
| 多对多：按顺序 | 4,2 / 1,3 | 4–1、2–3 |
| 多对多：全部组合 | 1,2 / 3,4 | 1–3、1–4、2–3、2–4 |
| 原子组对原子组 | 1,2 / 3,4 | {1,2}–{3,4} |

编号从 1 开始。重复编号去重但保留首次出现顺序；按顺序配对要求两侧数量相同。每个配对的两个片段不能包含相同原子。越界编号、反向范围及缺失元素均明确报错，不再静默丢弃。

## 计算与导出

- 多体系任务在各自体系内部配对，不会计算不同结构之间的键长。
- 首期支持 `vasprun.xml` 和具有原子分辨 PDOS 的 `DOSCAR`。已预先合并的 VASPKIT PDOS 文件继续使用单次分析。
- 大型文件按体系集中提取原子数据，复用于该体系的所有配对；已完成结果暂存磁盘，不把所有结果常驻内存。
- 合并 Fragment 使用求和；total 与其分轨道同时显示不会在 Overlap 或带中心计算中重复计数。
- 各体系能量使用自身的 `E−Ef`。积分范围和配色采用主窗口当前设置。
- 导出为每次操作创建独立目录，含各任务的 PNG（200 DPI）、SVG、DOS CSV，以及汇总带中心的 `summary.csv`、记录输入和分析设置的 `tasks.json`。导出错误不会阻断其他任务。
- 工作区保存原子映射与配对方式；保存计算结果请使用批量导出。
- 取消会在当前文件读取或当前导出完成后生效。文件在预览后被替换时，必须重新预览。

按距离自动生成配对、批量键长和跨体系并排图属于后续阶段。本次批量结果界面会明确说明未执行键长分析。
