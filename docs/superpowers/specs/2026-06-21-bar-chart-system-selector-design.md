# 柱状图体系选择器设计

## 目标

为主界面的 Comparison Bar Chart 增加体系筛选，用户可决定绘制哪些已完成计算的体系。现有柱状图的颜色、排序、标签、坐标轴、图例、导出和样式对话框行为保持不变。

## 交互

- 在柱状图工具栏增加 `Data` 按钮。
- 点击打开可多选的勾选下拉框，选项为当前 `results_data` 中去重后的体系标签。
- 第一次加载计算结果时，全部体系默认勾选。
- 后续计算刷新结果时，仍存在的体系保留原勾选状态；新体系默认勾选；已不存在的体系移除。
- 每次勾选变化立即重绘。
- 若无体系被选中，图表画布清空，不改变任何样式参数或其它图表的数据。

## 数据流

`MainWindow._on_calculation_done()` 继续调用 `BarChartWidget.update_chart(results_data)`。

`BarChartWidget` 保存完整结果列表，勾选状态只作为显示过滤器。渲染前按选中的 label 过滤结果，再沿用既有分组柱状图绘制流程。因此 CSV、表格、PDOS 图和 Multi-System PDOS 不受影响。

## 实现边界

- 复用项目已有可勾选下拉控件，避免新增平行的选择模型。
- 不修改任何数值计算、DOS 解析或积分逻辑。
- 不改变已有 Pattern、Labels、Axes、Legend 控件及默认值。

## 验证

自动化测试覆盖：初始全选；取消一个体系后仅该体系结果不传入绘制；刷新数据后保留有效选择并默认选中新体系；取消全部时安全清空画布。
