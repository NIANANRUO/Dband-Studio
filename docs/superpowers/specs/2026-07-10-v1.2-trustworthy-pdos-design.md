# DBand Studio v1.2 Trustworthy PDOS Design

## Goal

Every displayed number must come from an identifiable source layout, a real
projected orbital, and a recorded calculation method. Unsupported or ambiguous
data must fail with a repair path instead of producing plausible zeros.

## Architecture

`DataLoader.inspect()` produces immutable `PDOSCapabilities`. Parsers validate
column layout and attach those capabilities to `PDOSMetadata`. Calculation and
hybridization services consume only validated channels. The UI presents the
same capabilities at import time and disables choices absent from the source.

The historical five-item parser tuple remains compatible. Metadata-aware
callers opt into the six-item API. Ordinary VASP PDOS remains angular-momentum
resolved; principal quantum numbers are outside the data contract.

## Failure Policy

Integrity, unsupported layout, ambiguous layout, structure mismatch, orbital
availability, and atom selection are distinct errors. Field-less layouts are
accepted only for common VASP 5/6 column counts with one physical mapping.

## Release Gates

Automated tests must pass on Python 3.10-3.13. Release candidates additionally
require local end-to-end checks against unmodified VASP 5 and VASP 6 outputs,
plus Windows installer install, upgrade, and uninstall checks.
